# KBScores - Real-Time Football Scores & Predictions

A comprehensive Android application providing real-time football scores, match predictions, and detailed statistics, with special focus on Lesotho football leagues.

## Features
- ⚽ Real-time live scores (updated every 15-30 seconds)
- 🇱🇸 Complete Lesotho Premier League coverage (All 16 teams)
- 🔮 AI-powered match predictions with confidence levels
- 📊 League standings and live statistics
- 🌍 1,000+ international leagues supported
- 📱 Dark/Light theme support
- 💾 Offline mode with cached data
- 🔔 Push notifications for goals and match events
- 📈 Head-to-head history and team form analysis

## Technology Stack
- **Language:** Kotlin
- **UI Framework:** Jetpack Compose
- **Architecture:** MVVM + Clean Architecture
- **Database:** Room (for offline caching)
- **DI:** Hilt
- **Networking:** Retrofit + OkHttp
- **Async:** Coroutines + Flow
- **Image Loading:** Coil
